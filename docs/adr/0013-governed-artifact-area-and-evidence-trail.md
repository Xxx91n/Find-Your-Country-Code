# 0013 — 证据与工作区治理：`.scratch/` 为受管工件区、外部输入留痕三件套、防误吞门禁

状态：accepted | 日期：2026-09-18 | 来源：Cycle-8 grill D-003 · D-004 · D-005 · D-007（行业对标：`.scratch/cycle8-grill/research/q3-evidence-workspace-governance.md`，12 条来源）

## 决策

1. **`.scratch/` 是受管工件区，不是可抛弃现场。** 其内容**不可抛弃**、**必须保持 Git 跟踪**、**原地保留**（不迁出）。判据不是目录名，而是「内容是**人写/裁决的产物**还是**工具可再生成的产物**」＋「是否被构建/验证链消费」——被 CI 门禁读取的文件**自动升级为受管**。（**否决**「回归可抛弃」与「降级为 advisory」两条路线：后者经取证仅覆盖 5 个 CI 依赖脚本中的 1 个。）
2. **受管区内部分区**：`evidence/`（不可再生证据，**永不清理**）与 `draft/`（真可抛弃的探针脚本与调研草稿，**允许清理**）；边界写入目录 README，**清理脚本只允许触碰 `draft/`**。
3. **外部输入留痕三件套**：任何**不可再生**的外部输入（第三方评审、审计报告、外部工具产出）—— ① 入库受管区；② 台账记录 **SHA-256 + 来源 URL + 抓取日期**；③ push 到远端。**不得**落在任何被忽略目录。
4. **被忽略目录的边界**：`dist/` · `test-results/` · `playwright-report/` · `live-out/` **保持忽略**（可再生产物；业界共识：构建产物入库是反模式、测试/浏览器报告走 CI artifacts）。但 **`live-out/` 须复核**：若含「站点行为基准」则按 golden file 规则**晋升入库**。
5. **防误吞门禁**：CI 加一步 `git check-ignore -v` 断言关键路径**不被忽略**（`git check-ignore -v` 是官方调试命令，能打印「哪一行哪条规则吞了它」）。`docs/*` 的「宽忽略 + 白名单」写法**落在 gitignore 官方范例的合法形态内**，**不重写**，由本门禁兜住。
6. **findings register**：审计发现与残留**不散落**，收进一个带**日期与复核期限**的登记册；例外记录五要素 = 发现 ID · 理由 · 补偿性控制 · 具名签核 · **到期日（绝不自动续期）**。

## 事故回溯（本条的直接动因）

一份放在**被忽略目录**（`test-results/`）里的**第三方评审原文**，因目录清理而**永久丢失**：因 `.gitignore:25` 忽略该目录，该文件**从未入库**、删除后**无任何版本控制痕迹**、**不可恢复**（实测：工作区零命中、`git ls-tree HEAD` 零命中、`git log --diff-filter=D` 零命中、广域搜索零命中）。

**根因**：不可再生证据落在可抛弃区且**无留痕**（既没存原件、也没存指针+哈希）。
**流程修正**：即本 ADR 决策 3 的「留痕三件套」＋ 决策 4 的「外部输入不得落被忽略目录」。

## 后果

- `.scratch/architecture-recovery/`（`issues/` + `research/`）正式转为**受管工件**（与 `tests/`、`docs/` 同级）；其被 CI 门禁读取属**合法依赖**（5 个脚本：`verify-ticket-06/08/10/12` + `issue-checkbox-audit`）。
- **不得**再以「临时目录／可抛弃现场」使用 `.scratch/`；其删除／清理须走正常评审。
- 4 个**反向断言门**（`verify-ticket-07/10/11/12` 断言 workflows 零 `.scratch/` 路径引用）**不得移除或削弱**——「受管」**不等于**「允许 workflow 直接引路径」。
- 决策账本（唯一权威需求面）**不得**置于任何被忽略目录。

## 反证条件

- 若 `.scratch/` 体量增长到影响 clone／CI 时长并出现可复现的工程痛点 → 重评决策 1（改为「受管集迁出 `.scratch/`」）。
- 若 CI 平台提供 artifacts 保留能力 → 重评决策 4（测试／浏览器报告迁 artifacts）。
- 若 `live-out/` 被证实**仅含诊断输出**、无「站点行为基准」→ 决策 4 的复核项关闭。
