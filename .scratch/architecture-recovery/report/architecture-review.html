Find-Your-Country-Code v1.3.4

2026-09-03AutoCoder · 架构大脑依据 improve-codebase-architecture

现状

单文件油猴脚本（42KB，IIFE），六个隐藏静态对象（Detect / Fill / UI / Store / COUNTRIES / observer）。唯一真实 seam 是 Detect.scan 与 Fill.run；无导出、无测试缝、无置信度模型。

痛点 ↔ 根因映射
用户痛点代码根因（observed）
误检测：不是选区号的字段也有图标布尔命中即注入，无置信度；prefix 歧义词；裸词"区号"；纯数字 option 误判；国家 select 与区号 select 混同
大部分网站不生效Shadow DOM 盲区；框架组件库伪 select 不识别；autocomplete/inputmode 信号全盲；_done 终态化；iti 版本碎片化

候选（按推荐强度）

C1 · 检测引擎重构：布尔 → 多信号加权评分 Strong

Detect 区块 · CONFIG 词表 · _process
方案

五层信号瀑布：L0 autocomplete token（tel-country-code 一票强命中）→ L1 词表/label 加权 → L2 锚字段关联（tel 主号 ⇄ 区号字段互证）→ L3 options 内容验证 → L4 排除词负分。输出 score + 信号明细，分级行动：高分自动注入 / 中分低视觉权重 / 低分不注入。

收益

误报从"黑名单穷举"变"阈值可控"；测试面收敛为纯函数 scoreElement(el)→{score,signals}。行业共识：Chromium / Bitwarden / KeePassXC 独立收敛于同一蓝图（cited）。

C2 · 模块化工程 + Playwright E2E Strong

src/ 全体 → vite-plugin-monkey + TS + test/ fixture 集
方案

拆 detect / fill / ui / store / data / rules 模块，构建产物仍单 .user.js（GreasyFork 发布链不变）；3 个手工测试页升级为 Playwright fixture 断言（含误报样本"不插图标"用例）。

收益

每票独立模块 → GitButler 并行波次真并行；检测引擎可测（当前为 0 测试缝）。

C3 · iti 适配层独立化 Worth exploring

Fill.fillIti 五层 fallback · Detect._isIti

getInstance 稳锚（v16→v29 从未断代）+ setSelectedCountry/setCountry 双名 + 双代 DOM 类名矩阵，覆盖 v16–v29（atomcode 版本矩阵 cited）。

C4 · 可重评估扫描 + Shadow DOM 穿透 Worth exploring

Detect._done · Detect.scan · observe()

WeakSet 终态 → 指纹快照重评；递归穿透 open shadowRoot + 每 root 单独 observer；SPA 路由 hook 定向重扫。KeePassXC 生产同款心智（cited）。

站点豁免/强制选择器/置信度覆盖 + 面板"这里不是区号字段"一键负反馈。三源收敛：KeePassXC sites.js / Bitwarden linked field / 1Password data-1p-ignore（cited）。
