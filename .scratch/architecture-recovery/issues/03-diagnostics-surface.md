# 03: 诊断面

**What to build:** 让脚本能回答「各工具是否生效、为何未生效」：一份结构化诊断事件流作唯一事实来源，面板与机器可读输出是其两个 serializer；覆盖全链路四层判定。

**Blocked by:** None（可立即开工）

**Status:** ready-for-agent

**覆盖 A-xxx:** A-028


- [ ] 诊断事件流为唯一数据源，面板与机器可读输出从同一份数据渲染（不得各自采集）
- [ ] 四层判定全链路：工具失效 / 注入失效 / 脚本逻辑失效 / 写入结果（提交前状态→写入动作→提交后断言）
- [ ] 独立诊断视图（决策链时间线 + 过滤器 + 导出）+ 既有界面做入口与摘要
- [ ] 入口收敛为一个 GM 菜单项（不为每个诊断功能各设菜单项）
- [ ] 分级门控：error/warn 与计数器恒开；全链路 trace 门控且惰性构造；环形缓冲有容量上限
- [ ] fail 记录的 reason 指向已验证因果；诊断不挂运行热路径
- [ ] 声明本票覆盖的 A-xxx：A-028
