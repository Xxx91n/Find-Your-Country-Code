## 4. ⚠️ 两个坑（本窗口实测踩过，下一窗口必读）

### 坑 1 —— `/tmp` 在 bash 与 Node 下是**两个不同目录**（FN-01）

- bash `/tmp` = `%TEMP%`（`C:/Users/Administrator/AppData/Local/Temp`）
- Node `path.resolve('/tmp/x')` = **`D:\tmp\x`**（按当前盘符解析）

⇒ 「脚本 `--json /tmp/x.json` 写、Node `require('/tmp/x.json')` 读」会**读到另一个文件**。本窗口曾因此读到**昨日残留**，得出错误的 `cases=56 / scanSelectors=10`，几乎误判为「改动引入回归」。
**规避**：产物输出一律用**无歧义绝对路径**（如 `D:/tmp/...`）；基线对照用 `git archive HEAD` 隔离重建。

### 坑 2 —— LF 清账会产生 **index stat 幽灵**（FN-02）

字节级 LF 归一后，git 与 GitButler 均报 **121 条 `M`**，但**内容零差异**（`git hash-object -- <f>` == index blob == `HEAD:<f>`；`git diff --numstat` 空；`but diff` 报 “No diff available”）。
**规避/处置**：用 **`but discard <id>`**（`but` 唯一入口，**不要用裸 `git add` / `git update-index`**）分枇清除；清除后逐路径校验 hash 不变。
