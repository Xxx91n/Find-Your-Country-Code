CCH 脚本测试页
Find-Your-Country-Code · Userscript Testbed
使用前请先安装脚本： 在 Tampermonkey / Violentmonkey 中安装 Find-Your-Country-Code (GreasyFork)， 刷新此页后，下方各类电话区号字段旁应出现 🌐 图标，点击即可搜索并填入国家区号。
场景 A — 原生 <select> 区号下拉 SELECT

最常见场景：网站用 <select> 列出国家列表，option value 为 +1、+86 等区号或 ISO 代码，脚本应能识别并注入 🌐 按钮。

A1 — option value 为 "+86" 格式（name="country_code"）

A2 — option value 为 ISO 代码（CN, US…）

A3 — Select + Input 横排电话行

场景 B — <input> 文本框区号 INPUT

部分网站用 input 让用户手动输入区号，脚本应识别 name/id 含 "code"、"dial"、"country"、"calling" 等关键词的字段。

B1 — input[name="country_code"]

B2 — input[name="dial_code"]

B3 — input[id="callingCode"] + input[id="phonePrefix"]

场景 C — intl-tel-input 插件 intl-tel-input

intl-tel-input 是最流行的电话输入库，内置旗帜下拉。脚本应能识别 .iti 容器并注入 🌐 按钮，填写后同步更新 iti 实例的国家选择状态。

C1 — 单个 intl-tel-input，initialCountry: "cn"

C2 — 双实例（主号 + 紧急联系人）

场景 D — 动态注入字段 MutationObserver

脚本用 MutationObserver 监听 DOM 变化。点击下方按钮动态插入不同类型的区号字段，验证脚本能否在注入后自动检测并添加 🌐 按钮。

注入控制面板

点击上方按钮动态注入字段，观察脚本是否自动识别并添加 🌐 按钮
场景 E — 综合注册表单

同时包含 select、input、intl-tel-input 三种字段的完整注册表单，模拟真实注册场景，可一次性验证脚本的多字段识别能力。
