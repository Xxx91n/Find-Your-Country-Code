## v1.5.0 更新日志

- 新增：弱线索国家/区号字段也能被识别——缺少可见文字标签、仅靠 name / id / placeholder / aria 等属性线索的字段由「不识别」提升为低调注入（悬停恢复）；固话本地区号、称呼前缀、纯数字枚举等易混淆字段仍不误报。
- 新增：识别 `option value` 为 ISO 国家代码且带括号区号的下拉（如 `CN (+86)`）；纯 ISO2 国家选择器（不含区号）仍不误报，+1 / +44 等共享区号按国家名消歧不受影响。
- 新增：无 ARIA 语义的手写自定义下拉（可聚焦的 div / span 容器）纳入扫描候选，可登记并从面板手动召唤填充。
- 修复：站点规则中的「强制分档」只对显式标记为页面级的规则生效，元素级规则不再被当作整页覆盖——一条元素级规则不会再影响整站字段。
- 修复：填充结果可观测——区分「已填充 / 已复制 / 失败」三种结果，检测到区号格式分歧（+86 / 0086 / 86）时给出提示；填充失败不再静默提示「已复制到剪贴板」。
- 安全：跨帧与跨标签页通信（postMessage / BroadcastChannel）增加来源校验，不再接受任意来源的消息。
- 优化：全量 TypeScript strict 类型收敛，构建期类型错误清零；依赖版本钉死、CI 门禁瘦身，发布产物不变。

## v1.4.0 更新日志

- 新增：多信号加权评分自动识别国家/区号字段（`select`、`input`、intl-tel-input 场景），按置信度分级行动——高置信自动注入 🌐 图标、中置信低调注入（悬停恢复）、低置信可从面板手动召唤；称呼前缀、固话本地区号、纯数字枚举等易混淆字段不再误报。
- 新增：站点规则与负反馈——对误报字段一键负反馈即时抑制（幂等、可撤销），支持豁免域名、强制选择器与分档覆盖，面板内管理规则。
- 新增：intl-tel-input v16–v29 全版本适配；React/Vue 等受控组件经原生事件序列真实同步填充。
- 优化：动态页面兼容——MutationObserver 自动扫描 + SPA 路由切换重评，穿透 open Shadow DOM。
- 优化：🌐 触发图标低调样式可配置（变暗/隐藏）。
- 优化：工程迁移至 vite-plugin-monkey 模块化构建，发布产物不变，维护性提升。
- 新增：iframe 拆分表单支持——每个帧内独立检测与填充，选择面板仅在顶层出现，收藏与站点规则跨帧一致。
- 新增：组件库伪下拉（MUI/AntD/Element/react-select/Radix 等）识别——先登记再从面板手动召唤，两种 combobox 形态（可编辑/仅选择）均可填充。
- 新增：React 19 受控组件填充兜底——能力探测失败时自动走强制同步路径，提交值真实生效。
- 优化：隐藏/装饰性字段（clip-path、content-visibility、遮挡、零尺寸）不再挂图标，可从面板手动召唤。
- 优化：内容验证加码——共享区号（+1/+44）选项按国家名消歧、「请选择」占位项不参与计分，误报进一步下降。
- 优化：intl-tel-input 识别并入统一评分引擎，iti 容器内无关字段不再无条件挂图标。

## v1.3.4 更新日志
