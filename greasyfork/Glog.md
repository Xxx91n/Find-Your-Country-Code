## v1.7.0 更新日志

- 新增：面板「设置」入口进了油猴菜单——即使整页字段都没被识别，也能从菜单直接打开面板并跳到设置；语言等设置不再“藏”在面板深处。
- 优化：面板语言切换改为「自动 / 中文 / English」三选一显式控件，当前选中项一眼可见；切换后面板文案、图标提示、收藏行提示、空态文案一次性全部刷新，不再残留旧语言。
- 新增：诊断视图——把「这个字段为何被/未被识别、注入到了哪一档、写入了什么值」按四层（工具 / 注入 / 逻辑 / 写入）摊开，可导出为文本；默认只记错误与告警，需要细节时可开全链路追踪。
- 修复：嵌套表单（iframe / 内嵌 srcdoc 页面）里「选完国家没反应」的问题——此前内嵌帧的来源校验会误判并静默丢弃填充指令；现已修复，嵌套表单的填充链路真正跑通。
- 优化：intl-tel-input 字段的填充结果改按「选中国家状态」判定（此前按宿主输入框的 value 读，而 ITI 官方语义本就不保证写入该值），判定更贴合实际行为。
- 优化：站点规则条数上限的强制点移到写入路径（超限直接拒绝写入），不再出现内存中超限的规则文档。
- 测试：真实站点层从“只看图标有没有注入”升级为五级阶梯（存在性 → 注入 → 交互 → 写后读回 → 用户反馈），并建立自有镜像页 + 结构骨架语料，发布前自动把关。
- 新增：发布门——真实站点层最近一次运行不绿时阻断出包（除非显式 ack 并立票），避免带着已知问题发版。

## v1.6.0 更新日志

- 新增：面板全局入口——从油猴菜单可直接打开选择面板，不再依赖页面字段是否出现 🌐 图标；此前「整页字段置信度不足 → 无图标 → 面板打不开」的死路已消除，低置信字段也能从面板手动召唤。
- 优化：低调注入图标改到字段右缘内侧，不再被表单容器的 overflow 裁掉；同时降低「广告感」（去高饱和、去重阴影），更易被注意到。
- 新增：面板语言可切换（跟随浏览器 / 中文 / English），选择经油猴存储持久化，不再只能跟随浏览器语言。
- 修复：嵌套 iframe（含 Shadow DOM 包裹、多层嵌入）场景下点击图标不再无响应——面板可由顶层代开；来源校验失败时给出可见提示，不再静默无反馈。
- 安全：跨帧来源校验在覆盖更全的同时保持严格（同源强制比对 origin、跨域退化为来源引用比对），不放宽安全边界。
- 优化：依赖安装冲突根治（React 18/19 分居独立安装根），构建与测试链路更稳定。

## v1.5.0 更新日志

- 新增：弱线索国家/区号字段也能被识别——缺少可见文字标签、仅靠 name / id / placeholder / aria 等属性线索的字段由「不识别」提升为低调注入（悬停恢复）；固话本地区号、称呼前缀、纯数字枚举等易混淆字段仍不误报。
- 新增：识别 `option value` 为 ISO 国家代码且带括号区号的下拉（如 `CN (+86)`）；纯 ISO2 国家选择器（不含区号）仍不误报，+1 / +44 等共享区号按国家名消歧不受影响。
- 新增：无 ARIA 语义的手写自定义下拉（可聚焦的 div / span 容器）纳入扫描候选，可登记并从面板手动召唤填充。
- 修复：站点规则中的「强制分档」只对显式标记为页面级的规则生效，元素级规则不再被当作整页覆盖——一条元素级规则不会再影响整站字段。
- 修复：填充结果可观测——区分「已填充 / 已复制 / 失败」三种结果，检测到区号格式分歧（+86 / 0086 / 86）时给出提示；填充失败不再静默提示「已复制到剪贴板」。
- 安全：跨帧与跨标签页通信（postMessage / BroadcastChannel）增加来源校验，不再接受任意来源的消息。
- 优化：全量 TypeScript strict 类型收敛，构建期类型错误清零；依赖版本钉死、CI 门禁瘦身，发布产物不变。

## v1.4.0 更新日志
